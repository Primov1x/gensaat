# Gensaat

Ein Aufbauspiel im Stil von Kittens Game: ein Space-Marine-Orden baut auf Kharos Tertius sein Festungskloster wieder auf.
Läuft im Browser, am PC und am Handy (zum Startbildschirm hinzufügen, dann auch offline).

Lokal: `python serve.py 8934`, dann http://localhost:8934 · Tests: `node test.js` · Tempo: `node test.js tempo`

Inoffizielles, nicht kommerzielles Fanprojekt. Warhammer 40,000 und alle zugehörigen Namen sind Marken von
Games Workshop Ltd.; dieses Projekt steht in keiner Verbindung zu Games Workshop.
